      05書き出し

      1. 「works.js を書き出す」でファイルを保存します（ダウンロードフォルダに入ります）。
      2. GitHub のリポジトリを開き、Add file → Upload files で保存した works.js をアップロードします（同じ名前のファイルは上書きされます）。
      3. Commit changes を押すと、1〜2分で公開サイトに反映されます。
